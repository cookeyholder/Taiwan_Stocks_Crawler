# 自動化排程

## cron 排程（Linux/macOS）

每個交易日收盤後（約 14:00）自動抓取資料：

```cron
# 每個工作日 18:00 抓取今日資料
0 18 * * 1-5 /path/to/stock-cli fetch --today --db /path/to/market_data.db
```

### 搭配日誌輸出

```cron
# 將輸出寫入日誌檔案
30 18 * * 1-5 /path/to/stock-cli fetch --today >> /var/log/stock-crawler.log 2>&1
```

## 批次補檔

初次使用或需補齊歷史資料時：

```bash
# 補單日
stock-cli fetch --date 2026-01-01

# 補區間（需在應用程式中批次操作）
# Tauri 桌面應用提供 batch_download 功能
```

## Windows 工作排程器

1. 開啟「工作排程器」
2. 建立基本工作
3. 觸發程序：每日，只限工作日
4. 動作：啟動程式，路徑指向 `stock-cli.exe`
5. 引數：`fetch --today --db C:\path\to\market_data.db`

## 資料庫維護

- **定期備份**：建議每週備份 SQLite 資料庫檔案
- **清理資料**：使用 Tauri 桌面應用的「刪除日期區間」功能釋放空間
- **重建索引**：SQLite 會自動維護索引，一般不需手動操作
