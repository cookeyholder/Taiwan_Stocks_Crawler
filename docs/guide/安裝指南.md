# 安裝指南

## 系統需求

| 平台 | 需求 |
|------|------|
| **Linux** | Rust、libxkbcommon-x11、Vulkan 支援（可選） |
| **Windows** | Rust（MSVC 工具鏈）、Direct3D 12 支援 |

### Linux 系統套件依賴

```bash
sudo apt install build-essential pkg-config libxkbcommon-x11-0 libvulkan1 curl
```

### 安裝 Rust

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

## 從原始碼編譯

### CLI 工具

```bash
cargo build -p stock-cli --release
# 輸出：target/release/stock-cli（或 stock-cli.exe）
```

### 桌面應用（GPUI）

使用純 Rust 與 Cargo 進行建置，無需安裝 Node.js 或前端工具鏈：

```bash
# 透過專屬腳本（自動驗證依賴並複製到 dist 目錄）
./scripts/build-linux.sh       # Linux
powershell ./scripts/build-windows.ps1 # Windows

# 或直接使用 cargo
cargo build --release -p stock-gpui
```

輸出路徑：`dist/` 或 `target/release/stock-gpui`（Windows 為 `stock-gpui.exe`）。

## 初次執行

### CLI 模式

```bash
# 抓取今日資料
cargo run -p stock-cli -- fetch --today

# 布林擠壓選股
cargo run -p stock-cli -- screen
```

### 桌面應用啟動

```bash
cargo run -p stock-gpui
```
