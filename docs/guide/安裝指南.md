# 安裝指南

## 系統需求

| 平台 | 需求 |
|------|------|
| **Linux** | Rust、Node.js >= 18、libwebkit2gtk-4.1-dev 等系統套件 |
| **Windows** | Rust、Node.js >= 18、Visual Studio Build Tools（C++ 桌面開發）、WebView2（內建於 Win 10+） |

### Tauri 系統依賴（Linux）

```bash
sudo apt install libwebkit2gtk-4.1-dev libgtk-3-dev libglib2.0-dev \
                 libsoup-3.0-dev libjavascriptcoregtk-4.1-dev librsvg2-dev \
                 libdbus-1-dev libssl-dev libayatana-appindicator3-dev \
                 build-essential curl wget file pkg-config
```

### 安裝 Rust

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

## 從原始碼編譯

### CLI 工具

```bash
cargo build -p stock-cli --release
# 輸出：target/release/stock-cli（或 stock-cli.exe）
```

### 桌面應用（Tauri）

```bash
cd stock-tauri
npm install
npm run tauri build
```

輸出路徑：`stock-tauri/src-tauri/target/release/bundle/`，視平台產生 deb、rpm、msi 或 nsis 安裝檔。

## 初次執行

### CLI 模式

```bash
# 抓取今日資料
cargo run -p stock-cli -- fetch --today

# 布林擠壓選股
cargo run -p stock-cli -- screen
```

### 桌面應用開發模式

```bash
cd stock-tauri
npm install
npm run tauri dev
```
