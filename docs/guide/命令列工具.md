# stock-cli CLI 使用說明

`stock-cli` 是臺股選股工具的 Rust 命令列入口，支援資料抓取、布林擠壓選股與 yfinance 同步。

## 全域選項

| 選項          | 說明              | 預設值                       |
| ------------- | ----------------- | ---------------------------- |
| `--db <PATH>` | SQLite 資料庫路徑 | `market_data.db`（當前目錄） |
| `--help`      | 顯示說明          | —                            |

## 子指令

### fetch — 下載市場資料

```bash
# 今日資料（TWSE JSON API + TPEX JSON API）
stock-cli fetch --today

# 指定日期
stock-cli fetch --date 2026-06-10

# 指定資料庫路徑
stock-cli fetch --today --db /tmp/market.db
```

資料來源路由邏輯：

| 請求日期 | TWSE                               | TPEX     |
| -------- | ---------------------------------- | -------- |
| 今日     | JSON API（`openapi.twse.com.tw`）  | JSON API |
| 歷史日期 | CSV API（`MI_INDEX?response=csv`） | JSON API |

### screen — 布林通道選股

以布林通道 bandwidth 門檻篩選 squeezed 標的。

```bash
# 預設條件（max_bandwidth=0.08, min_days=5）
stock-cli screen

# 自訂條件
stock-cli screen --max-bandwidth 0.05 --min-days 5 \
                 --types stock,etf --min-volume 1000000
```

參數說明：

| 參數              | 說明                     | 預設值 |
| ----------------- | ------------------------ | ------ |
| `--max-bandwidth` | 最大 bandwidth 門檻      | 0.08   |
| `--min-days`      | 最低連續擠壓天數         | 5      |
| `--types`         | 商品類型篩選（逗號分隔） | 全部   |
| `--min-volume`    | 最低成交量               | 0      |

### sync — 同步 yfinance 歷史資料

```bash
# 同步指定標的
stock-cli sync --symbol 2330
```

> **注意**：yfinance 後端仍在開發中。
