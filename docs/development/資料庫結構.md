# 資料庫 Schema

使用 SQLite。Tauri 桌面應用預設路徑為 `{data_dir}/stock-screener/market_data.db`，可透過環境變數 `STOCK_DATA_DIR` 自訂。CLI 工具預設為當前目錄的 `market_data.db`，可透過 `--db` 參數指定。

## 表格定義

### market_quote_core — 標準化報價

主鍵：`(trade_date, market_code, symbol_clean)`

| 欄位 | 型別 | 說明 |
|------|------|------|
| `trade_date` | TEXT | 交易日（西元 YYYY-MM-DD） |
| `market_code` | TEXT | `TWSE` 或 `TPEX` |
| `symbol_raw` | TEXT | 原始股票代號（可能含 `=` 前綴） |
| `symbol_clean` | TEXT | 標準化股票代號 |
| `security_name` | TEXT | 證券名稱 |
| `instrument_type` | TEXT | 商品類型，預設 `other` |
| `instrument_subtype` | TEXT | 商品子類型 |
| `isin_code` | TEXT | ISIN 國際編碼 |
| `cfi_code` | TEXT | CFI 編碼 |
| `section_label` | TEXT | 產業別 |
| `open_price` | REAL | 開盤價 |
| `high_price` | REAL | 最高價 |
| `low_price` | REAL | 最低價 |
| `close_price` | REAL | 收盤價 |
| `volume_shares` | INTEGER | 成交股數 |
| `turnover_value` | REAL | 成交金額 |
| `trade_count` | INTEGER | 成交筆數 |
| `change_sign` | TEXT | 漲跌方向（`+` / `-`） |
| `change_value` | REAL | 漲跌價差 |
| `last_bid_price` | REAL | 最後揭示買價 |
| `last_bid_qty_raw` | TEXT | 最後揭示買量（原始字串） |
| `last_ask_price` | REAL | 最後揭示賣價 |
| `last_ask_qty_raw` | TEXT | 最後揭示賣量（原始字串） |
| `pe_ratio` | REAL | 本益比 |
| `issued_shares` | INTEGER | 發行量 |
| `next_limit_up` | REAL | 漲停價 |
| `next_limit_down` | REAL | 跌停價 |
| `source_file` | TEXT | 資料來源檔案/URL |
| `source_encoding` | TEXT | 來源編碼 |
| `source_line_no` | INTEGER | 來源行號 |
| `ingest_run_id` | TEXT | 匯入批次識別碼 |
| `ingested_at` | TEXT | 匯入時間戳記 |

### market_quote_extension — 原始 Payload

主鍵：`(trade_date, market_code, symbol_clean)`，外鍵參考 `market_quote_core`

| 欄位 | 型別 | 說明 |
|------|------|------|
| `trade_date` | TEXT | 交易日 |
| `market_code` | TEXT | 市場代碼 |
| `symbol_clean` | TEXT | 標準化股票代號 |
| `raw_change` | TEXT | 原始漲跌欄位值 |
| `raw_payload` | TEXT | 原始 JSON/CSV payload |

### securities — 有價證券主檔

| 欄位 | 型別 | 說明 |
|------|------|------|
| `symbol_clean` | TEXT | 標準化股票代號（主鍵） |
| `market_code` | TEXT | 市場代碼 |
| `security_name` | TEXT | 證券名稱 |
| `updated_at` | TEXT | 最後更新時間 |

## 索引

| 索引名稱 | 表格 | 欄位 | 用途 |
|---------|------|------|------|
| `idx_market_quote_core_symbol_date` | `market_quote_core` | `symbol_clean, trade_date` | 加速個股查詢 |
