# 資料來源 API 參考

## TWSE（臺灣證券交易所）

### 今日資料 — JSON API

```http
GET https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL
```

回應為 JSON 陣列，每個元素包含：

| 欄位 | 說明 | 範例 |
|------|------|------|
| `Code` | 股票代號 | `"2330"` |
| `Name` | 證券名稱 | `"台積電"` |
| `TradeVolume` | 成交股數 | `"20,000,000"` |
| `TradeValue` | 成交金額 | `"1,200,000,000"` |
| `OpeningPrice` | 開盤價 | `"500.00"` |
| `HighestPrice` | 最高價 | `"505.00"` |
| `LowestPrice` | 最低價 | `"498.00"` |
| `ClosingPrice` | 收盤價 | `"502.00"` |
| `Change` | 漲跌 | `"+2.00"` |
| `Transaction` | 成交筆數 | `"15,000"` |

### 歷史資料 — CSV API

```http
GET https://www.twse.com.tw/rwd/zh/afterTrading/MI_INDEX?response=csv&date=YYYYMMDD&type=ALL
```

- date 參數為西元年月日（如 `20260610`）
- 回應為 Big5 編碼的 CSV
- 檔案前段含「每日收盤行情」等 metadata 行，需跳過
- 部分數值欄位含逗號千分位格式（如 `"10,053,434"`）
- 部分股票代號前方有 `=` 前綴（如 `=0050`），需去除

#### CSV 欄位對照

| 索引 | 內容 |
|------|------|
| 0 | 證券代號 |
| 1 | 證券名稱 |
| 2 | 成交股數 |
| 3 | 成交金額 |
| 4 | 成交筆數 |
| 5 | 開盤價 |
| 6 | 最高價 |
| 7 | 最低價 |
| 8 | 收盤價 |
| 9 | 漲跌(+/-) |
| 10 | 漲跌價差 |
| 11 | 最後揭示買價 |
| 12 | 最後揭示買量 |
| 13 | 最後揭示賣價 |
| 14 | 最後揭示賣量 |
| 15 | 本益比 |
| 16 | 發行量（選擇性） |

## TPEX（證券櫃買中心）

### JSON API（支援今日與歷史日期）

```http
GET https://www.tpex.org.tw/www/zh-tw/afterTrading/dailyQuotes?date={ROC_YEAR}/{MONTH}/{DAY}&type=S&response=json
```

- date 參數使用民國年（如 `115/06/10`）
- type=S 表示上櫃股票
- 回應 JSON 結構中的 `tables` 陣列，篩選 `title` 包含「上櫃股票」的 table

#### JSON 資料欄位對照

| 索引 | 內容 |
|------|------|
| 0 | 代號 |
| 1 | 名稱 |
| 4 | 漲跌 |
| 5 | 開盤 |
| 6 | 最高 |
| 7 | 最低 |
| 8 | 收盤 |
| 10 | 成交股數 |
| 11 | 成交金額 |
| 12 | 成交筆數 |
| 13 | 發行量（選擇性） |

## 編碼處理

TWSE CSV API 使用 **Big5** 編碼。`fetcher/twse.rs` 中的 `decode_big5_fallback()` 函式負責解碼：
1. 以 `encoding_rs::BIG5` 解碼
2. 若解碼結果不含 replacement character（`\u{FFFD}`）則採用
3. 否則 fallback 到 UTF-8 lossy 解碼
