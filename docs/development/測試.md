# 測試策略

## 測試分類

### Rust 單元測試（主力）

以 `#[cfg(test)]` 內嵌於各模組檔案中，使用 `cargo test` 執行。

| 模組 | 案例數 | 主要涵蓋 |
|------|--------|---------|
| `stock-core::analysis` | 8 | SMA、EMA、Bollinger Bands、RSI、MACD 純函式計算 |
| `stock-core::db` | 2 | SQLite schema migration、upsert 冪等性 |
| `stock-core::fetcher` | 6 | TWSE CSV/JSON 解析、TPEX JSON 解析、Big5 解碼、HTML parser |
| `stock-core::pipeline` | 11 | 數值解析 helper、漲跌欄位解析、normalize 流程 |

**合計：27 項（截至 2026-06-11）**

### 桌面端整合測試

使用 `gpui_kit::test` 驅動無頭測試視窗，驗證 UI 行為與渲染：

| 測試檔案 | 測試項目 |
|---------|---------|
| `stock-gpui/tests/app_test.rs` | 視窗開啟、GPU 渲染循環與生命週期 |
| `stock-gpui/tests/cjk_test.rs` | CJK 繁體中文字型載入、排版與注音輸入相容性 |
| `stock-gpui/tests/data_table_test.rs` | 證券清單萬筆資料虛擬滾動與多欄位點擊排序 |
| `stock-gpui/tests/chart_test.rs` | 日 K 線圖與成交量圖表渲染及紅漲綠跌配置 |
| `stock-gpui/tests/app_views_test.rs` | AppView 主外框分頁切換與深色/淺色主題即時更新 |

## 執行方式

```bash
# 完整測試（核心庫與桌面端）
cargo test --workspace

# 僅核心庫
cargo test -p stock-core

# 僅桌面端整合測試
cargo test -p stock-gpui

# Lint
cargo clippy -p stock-core
cargo clippy -p stock-cli
cargo clippy -p stock-gpui

# 格式化檢查
cargo fmt -p stock-core --check
```

## 新增測試準則

- **單元測試優先**：每個公開函式都應有對應的單元測試
- **使用真實資料**：測試 fixture 應使用取自實際 API 的樣本資料（而非人工編造）
- **邊界值測試**：空值、極端值、特殊字元（如全形符號）應有對應案例
- **Mock HTTP**：使用 `wiremock` crate 模擬 HTTP 回應，避免測試依賴外部 API
- **CI 相容**：測試不應依賴網路連線、GUI 環境或外部服務
