## 資料流

```
TWSE OpenAPI / TPEX API
         │
         ▼
   fetcher::twse / tpex
   ┌─────────────────────┐
   │ HttpClient           │
   │  (retry × 3,        │
   │   exponential backoff)│
   └─────────┬───────────┘
             │ ParsedRecord
             ▼
   pipeline::normalize_records()
   ┌─────────────────────┐
   │ 字串→數值轉換        │
   │ 民國年→西元年        │
   │ =前綴去除            │
   └─────────┬───────────┘
             │ CanonicalQuote
             ▼
   db::MarketRepository
   ┌─────────────────────┐
   │ upsert_core_batch() │
   │ sync_securities()   │
   └─────────┬───────────┘
             │
             ▼
   SQLite (market_quote_core / extension / securities)
             │
             ▼
   pipeline::screen() / get_analysis()
   ┌─────────────────────┐
   │ 布林擠壓選股         │
   │ SMA/EMA/RSI/MACD    │
   └─────────┬───────────┘
             │ ScreenResult / AnalysisResponse
             ▼
   CLI stdout / Tauri IPC → Vue 前端
```

## 模組職責

| 模組                   | 職責                                                            | 對外介面                                                      |
| ---------------------- | --------------------------------------------------------------- | ------------------------------------------------------------- |
| `fetcher::twse`        | TWSE 資料爬蟲：JSON API（今日）、CSV API（歷史）、HTML 備用解析 | `fetch_today_json()`, `fetch_history_csv()`                   |
| `fetcher::tpex`        | TPEX 資料爬蟲：JSON API（支援歷史日期）                         | `fetch_daily_json()`                                          |
| `fetcher::HttpClient`  | HTTP 請求封裝，含自動 retry（3 次）與 exponential backoff       | `get()`, `get_bytes()`                                        |
| `db::MarketRepository` | SQLite 操作：upsert、查詢、布林篩選、migration                  | `open()`, `upsert_core_batch()`, `screen_bollinger_squeeze()` |
| `analysis`             | 技術指標純函式計算                                              | `sma()`, `ema()`, `bollinger()`, `rsi()`, `macd()`            |
| `pipeline`             | 端到端流程：fetch → normalize → upsert → screen/analysis        | `fetch_today()`, `fetch_date()`, `screen()`, `get_analysis()` |

## 關鍵資料型別

| 型別               | 階段           | 說明                                                   |
| ------------------ | -------------- | ------------------------------------------------------ |
| `ParsedRecord`     | fetcher 輸出   | 爬蟲原始資料，所有欄位為 `Option<String>`              |
| `CanonicalQuote`   | normalize 輸出 | 標準化報價，數值欄位已轉為 `Option<f64>`/`Option<i64>` |
| `OhlcvRecord`      | DB 查詢輸出    | OHLCV 時間序列，用於技術指標計算                       |
| `ScreenResult`     | 選股輸出       | 布林通道選股結果                                       |
| `AnalysisResponse` | Tauri 輸出     | 技術指標計算結果（含 K 線、MA、Bollinger、RSI、MACD）  |
