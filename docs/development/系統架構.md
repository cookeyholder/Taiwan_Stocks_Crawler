## 資料流

```
TWSE OpenAPI / TPEX API
         │
         ▼
   fetcher::twse / tpex
   ┌─────────────────────┐
   │ HttpClient           │
   │  (retry × 3,        │
   │   exponential backoff)│
   └─────────┬───────────┘
             │ ParsedRecord
             ▼
   pipeline::normalize_records()
   ┌─────────────────────┐
   │ 字串→數值轉換        │
   │ 民國年→西元年        │
   │ =前綴去除            │
   └─────────┬───────────┘
             │ CanonicalQuote
             ▼
   db::MarketRepository
   ┌─────────────────────┐
   │ upsert_core_batch() │
   │ sync_securities()   │
   └─────────┬───────────┘
             │
             ▼
   SQLite (market_quote_core / extension / securities)
             │
             ▼
   pipeline::screen() / get_analysis()
   ┌─────────────────────┐
   │ 布林擠壓選股         │
   │ SMA/EMA/RSI/MACD    │
   └─────────┬───────────┘
             │ ScreenResult / AnalysisResponse
             ▼
   CLI stdout / GPUI 事件驅動與 ViewModel 綁定 → GPU 渲染 (Direct3D / Vulkan / Metal)
```

## 模組職責

| 模組                   | 職責                                                            | 對外介面                                                      |
| ---------------------- | --------------------------------------------------------------- | ------------------------------------------------------------- |
| `fetcher::twse`        | TWSE 資料爬蟲：JSON API（今日）、CSV API（歷史）、HTML 備用解析 | `fetch_today_json()`, `fetch_history_csv()`                   |
| `fetcher::tpex`        | TPEX 資料爬蟲：JSON API（支援歷史日期）                         | `fetch_daily_json()`                                          |
| `fetcher::HttpClient`  | HTTP 請求封裝，含自動 retry（3 次）與 exponential backoff       | `get()`, `get_bytes()`                                        |
| `db::MarketRepository` | SQLite 操作：upsert、批次查詢、migration                       | `open()`, `upsert_core_batch()`, `get_batch_ohlcv()`, `get_active_symbols()`, `get_name_map()` |
| `analysis`             | 技術指標純函式計算                                              | `sma()`, `ema()`, `bollinger()`, `rsi()`, `macd()`            |
| `backtest::Strategy`   | 選股策略 trait（可插拔）                                        | `evaluate()`, `id()`, `min_history()`                          |
| `backtest::BacktestEngine` | 回測引擎：資料載入 → 策略評估 → 結果收集                   | `run_date()`, `run_range()`                                    |
| `backtest::bollinger`  | 布林擠壓策略實作                                                | `BollingerSqueezeBreakout`                                     |
| `pipeline`             | 端到端流程：fetch → normalize → upsert → screen/analysis        | `fetch_today()`, `fetch_date()`, `screen()`, `get_analysis()` |

## 關鍵資料型別

| 型別               | 階段           | 說明                                                   |
| ------------------ | -------------- | ------------------------------------------------------ |
| `ParsedRecord`     | fetcher 輸出   | 爬蟲原始資料，所有欄位為 `Option<String>`              |
| `CanonicalQuote`   | normalize 輸出 | 標準化報價，數值欄位已轉為 `Option<f64>`/`Option<i64>` |
| `OhlcvRecord`      | DB 查詢輸出    | OHLCV 時間序列，用於技術指標計算                       |
| `ScreenResult`     | 選股輸出       | 布林通道選股結果                                       |
| `Signal`           | 策略輸出       | 通用信號：has_signal、direction、strength、metadata    |
| `SignalRecord`     | 回測輸出列     | 單筆回測記錄，含日期、標的、方向、強度、策略名稱       |
| `BacktestOutput`   | 回測輸出       | 回測結果容器：`signals: Vec<SignalRecord>`             |
| `AnalysisResponse` | 分析查詢輸出   | 技術指標計算結果（含 K 線、MA、Bollinger、RSI、MACD）  |
