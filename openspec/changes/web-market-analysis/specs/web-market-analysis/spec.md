## Purpose

讓個人使用者能透過瀏覽器搜尋臺灣上市櫃股票、檢視本機保存的歷史行情與技術指標，作為選股和回測功能共用的唯讀資料基礎。

## ADDED Requirements

### Requirement: 證券清單與股票搜尋
網站 SHALL 從已匯入行情資料建立上市櫃證券清單，並提供依代號或名稱搜尋的 API 與介面；不得要求獨立證券表先完成同步才能搜尋。

#### Scenario: 依代號搜尋
- **WHEN** 使用者輸入有效股票代號
- **THEN** 系統顯示符合的代號、名稱與市場別

#### Scenario: 行情資料庫尚無證券
- **WHEN** 資料庫尚未匯入任何行情
- **THEN** 清單 API 回傳空清單，介面顯示尚無行情資料的空狀態

#### Scenario: 有行情但獨立證券表尚未同步
- **WHEN** 行情表已有代號與名稱，但 `securities` 表尚未同步
- **THEN** 搜尋仍可由已匯入行情顯示該證券

#### Scenario: 沒有符合的證券
- **WHEN** 搜尋條件沒有符合的證券
- **THEN** 介面顯示明確的無結果狀態且不顯示舊搜尋結果

### Requirement: 歷史行情查詢
API SHALL 接受股票代號及 ISO 格式 `start_date`/`end_date`，預設顯示最近兩年且單次顯示範圍不得超過五年，回傳依日期升冪排列的 OHLCV 行情。每筆資料須含交易日與最後匯入時間，不得把交易日誤稱為匯入時間。

#### Scenario: 查詢有資料的日期範圍
- **WHEN** 使用者選擇有效股票與日期範圍
- **THEN** API 回傳範圍內的行情，日期順序固定且不包含範圍外資料

#### Scenario: 日期範圍超出上限或格式錯誤
- **WHEN** 起訖日期格式錯誤、起日晚於迄日或顯示範圍超過五年
- **THEN** API 回傳欄位驗證錯誤且不執行無界查詢

#### Scenario: 查詢無資料的股票或區間
- **WHEN** 股票代號不存在或該區間沒有行情
- **THEN** API 以適當狀態回應，介面分別呈現錯誤或空資料狀態

### Requirement: 個股技術分析
網站 SHALL 顯示個股 OHLCV、移動平均線、布林通道、RSI 與 MACD，計算結果 SHALL 與 `stock-core` 相同。計算指標時 SHALL 使用顯示範圍起日以前所有可用行情，完成計算後才裁切顯示範圍。

#### Scenario: 顯示個股分析
- **WHEN** 使用者選定有足夠行情的股票與日期範圍
- **THEN** 系統顯示 K 線、成交量及所選技術指標，並呈現最後交易日的主要數值

#### Scenario: 歷史資料不足
- **WHEN** 行情筆數不足以計算某項指標
- **THEN** 系統明確顯示該指標目前無值，不以零值冒充有效結果

#### Scenario: 顯示範圍左界的指標值
- **WHEN** 使用者查詢的起日之前已有行情且指標需要前置資料
- **THEN** 起日當筆指標由起日前行情一併計算，與計算完整歷史後裁切的結果一致

### Requirement: 圖表日期與游標互動
個股分析圖表 SHALL 允許使用者調整可見日期區間，並以游標查看對應交易日行情；圖表不得只依賴顏色傳達漲跌。

#### Scenario: 游標查看 K 棒數值
- **WHEN** 使用者將游標移至圖表內一個交易日
- **THEN** 垂直提示線及數值資訊同步顯示該日 OHLCV 與可用指標

#### Scenario: 改變日期區間
- **WHEN** 使用者變更起訖日期
- **THEN** 圖表及摘要只呈現新範圍資料，且明確指出資料庫中沒有資料的空區間
