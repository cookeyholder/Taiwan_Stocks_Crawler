# 設計

- BSR 是當日查詢來源，匯入前拒絕無效日期及非當日日期，避免把當日資料標成歷史日期；同一日期的正規化值作為路徑元件。
- 客戶端必須確認 HTTP 狀態及明確的查詢成功訊號，才能讀取 CSV；解析器比對 CSV 標頭代號與請求代號。
- CSV 任何資料列剖析錯誤都使整份報表失敗，避免靜默寫入不完整資料。
- 全市場與自訂名單只處理資料庫已知 TWSE 股票；每日完成狀態記錄成功且零明細的查詢，但需在臺北時間 BSR 預計發布後（16:00）才可將無資料結果標記完成。
- CLI 單檔錯誤或批次部分失敗以非零退出碼結束，供排程器判斷。
- CAPTCHA 分類器的辨識字元涵蓋範圍須以已知答案樣本驗證；無法確認辨識結果時不可宣稱辨識成功。
