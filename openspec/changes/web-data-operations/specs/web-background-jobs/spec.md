## ADDED Requirements

### Requirement: 資料作業接入共用背景工作管理器
單日行情更新、日期區間補檔與 BSR SHALL 使用第三階段建立的共用背景工作管理器，沿用其工作識別碼、狀態、進度、結果查詢及持久化方式。建立資料作業時若已有長時間工作，系統 SHALL 立即拒絕；取消 SHALL 在目前來源請求完成後、開始下一個來源請求前停止。

#### Scenario: 建立並查詢資料作業
- **WHEN** 使用者建立通過驗證的單日更新、區間補檔或 BSR 工作
- **THEN** API 立即回傳工作識別碼，使用者可透過共用工作 API 查詢狀態、進度與完成摘要

#### Scenario: 資料作業遇到忙碌工作
- **WHEN** 另一個長時間工作仍在執行，使用者建立資料作業
- **THEN** 系統立即拒絕新工作並回報目前工作識別碼或忙碌狀態

#### Scenario: 取消進行中的來源擷取
- **WHEN** 使用者取消資料作業且目前來源請求尚未完成
- **THEN** 系統等待該請求完成，在開始下一個來源請求前停止並保留已寫入資料
